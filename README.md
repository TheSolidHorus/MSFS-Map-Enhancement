**MSFS Map Enhancement** replaces streamed ground tiles in MSFS 2020 and 2024. Google, Apple, ArcGIS. Building Enhancement 10.0.

## How to use
1. Download v10.0.
2. Extract `MSFS-Map-Enhancement.zip`.
3. Start the service. Allow the firewall prompt.
4. Pick a tile source. Load a flight with online world data on.

## FAQ

**Blank tiles?**
Start the service before the flight. Online world data must stay on. Notes in `files/tile/`.

**Xbox?**
Windows PC only.

## Requirements
Windows 10/11. MSFS 2020 or 2024.
